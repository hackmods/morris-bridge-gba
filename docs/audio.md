# Audio

Original chiptune score and sound effects for **Thomas's Bridge**. Generated by [`tools/gen_audio.py`](../tools/gen_audio.py).

## Legal

This is a parody game, **not** a licensed Thomas & Friends product.

The music is **original**. It aims for cheerful steam-railway / 1980s British children's-television energy (brass-like leads, chug bass, whistle bells). It does **not** reproduce the copyrighted *Thomas the Tank Engine* theme by Mike O'Donnell and Junior Campbell, nor any other licensed recording or melody.

## Cue map

| Cue | File | Screen | Loop |
|-----|------|--------|------|
| **Island Line March** | `audio/island_line.mod` | Title, all-levels complete | yes |
| **Knapford Yard** | `audio/yard.mod` | Level select | yes |
| **Workshop Shed** | `audio/workshop.mod` | Build mode | yes |
| **Full Steam** | `audio/full_steam.mod` | Test crossing | yes |
| **Peep** | `audio/peep.wav` | Test start | one-shot |
| **Chuff** | `audio/chuff.wav` | Synced to train sprite | one-shot |
| **Useful Engine** | `audio/useful.wav` | Level / game complete | one-shot |
| **Whistle** | `audio/whistle.wav` | Level complete (with Useful) | one-shot |
| **Snap** | `audio/snap.wav` | Strut break | one-shot |
| **Delay** | `audio/delay.wav` | Fail / no-path | one-shot |
| **Splash** | `audio/splash.wav` | Fall into the gap | one-shot |
| **UI tick** | `audio/ui.wav` | Menu move | one-shot |

Pause ducks music volume to 20% and restores it on resume.

## Formats (Butano / Maxmod)

- **Music:** ProTracker `M.K.` modules (4 channels). Direct Sound via `AUDIOBACKEND := maxmod`.
- **SFX:** 8-bit unsigned PCM, mono, 22050 Hz WAV.

Listenable 16-bit previews of the four loops live in [`audio_preview/`](../audio_preview/) (not imported by the ROM toolchain).

## Regenerating

```bash
python3 tools/gen_audio.py          # write assets
python3 tools/gen_audio.py --check  # validate WAV/MOD headers
```

Host tests run the checker: `make -C tests`.
