# Thomas's Bridge is a Game Boy Advance game

The whole point of this repository is a **Game Boy Advance** ROM.

- **Product:** `rom/thomas_bridge.gba` (Butano / C++20, header `THOMASBRIDGE` / `THOM01`)
- **Web:** mGBA-WASM playtest of that ROM at `/`. It is not a replacement game.
- **Do not** replace the GBA game with a high-resolution browser workshop, Poly Bridge clone, or canvas builder.
- **Do not** move the ROM to `/legacy.html` or treat the GBA look as “optional legacy.”

If a session goal, producer pass, or prior PR says otherwise, this file wins. See [docs/session-goal.md](docs/session-goal.md).
